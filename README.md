# Python Day 157 – Password Manager

## Description
A menu-driven Password Manager built using Python. It stores website account details and allows users to search, update and delete saved records.

**Educational project only:** Passwords are stored as plain text in JSON. Do not use real credentials.

## Features
- Add website account details
- View saved accounts
- Search by website
- Update passwords
- Delete accounts
- Store records using JSON

## Technologies Used
- Python
- JSON
- File Handling
- Lists and Dictionaries
- Functions

## Files
- `password_manager.py` – Main program
- `passwords.json` – Sample account data

## How to Run
```bash
python password_manager.py
```

## Concepts Learned
JSON file handling, searching, updating, deleting records and functions.
